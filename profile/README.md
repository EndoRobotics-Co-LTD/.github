# Endorobotics organization
- 해당 Github는 본사의 SW 엔지니어들의 효율적인 업무를 위해 생성된 공간임
- 총 3개의 팀이 하나의 organization을 같이 사용하고 있음
  - `Embedded` +  `IT-Strategy` + `AI`
 # CAUTION
- 해당 organization 내의 Repo 소스코드들은 **외부로 절대 유출되어서는 안됨**
- 각 사용자가 속한 팀의 Repo가 아니라면 타 팀의 Repo를 임의로 `pull`, `clone` 해서는 안됨
- 각 사용자마다 월 4달러의 요금을 지불하고 있기에 새로운 팀원을 초대하기 전 각 팀의 관리자에게 문의 필요
